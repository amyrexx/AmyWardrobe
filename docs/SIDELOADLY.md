# Установка через Sideloadly

Sideloadly — сторонняя программа (Windows/macOS) — подписывает IPA вашим Apple ID и ставит его на iPhone. Описание ниже
основано на общеизвестном порядке работы; интерфейс Sideloadly может меняться — сверяйтесь с его сайтом.

## Что понадобится
- Компьютер с Windows или macOS, USB-кабель, iPhone с iOS 17+.
- На Windows — **iTunes и iCloud, скачанные с apple.com** (не из Microsoft Store), иначе Sideloadly не увидит iPhone.
- Apple ID (бесплатного достаточно). Рекомендуется отдельный Apple ID для сайдлоада. **Пароль никогда не вводите в код, репозиторий или GitHub** — он вводится только в Sideloadly на вашем компьютере.

## Шаги
1. Скачайте IPA из GitHub Actions (см. README) и распакуйте ZIP.
2. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить → перезагрузка → подтвердить. (Пункт появляется после первой попытки установки сторонней подписи.)
3. Подключите iPhone кабелем, нажмите «Доверять этому компьютеру».
4. В Sideloadly выберите iPhone, перетащите `.ipa`, введите Apple ID, нажмите **Start**.
5. После установки: Настройки → Основные → **VPN и управление устройством** → ваш Apple ID → **Доверять**.
6. Запустите AmyWardrobe.

## Ограничения бесплатной подписи Apple
- Подпись действует **7 дней**; затем приложение перестаёт запускаться. Переустановите **поверх** тем же Apple ID — данные сохранятся. Sideloadly умеет автообновление при подключённом компьютере.
- Не более 3 приложений с бесплатной подписью одновременно; ограничение на число новых App ID в неделю.
- Bundle ID по умолчанию `com.amywardrobe.app` (Sideloadly может изменить его под ваш Apple ID — тогда при смене Bundle ID приложение считается *другим*, и данные не перенесутся: используйте резервную копию).
- Неподписанный IPA напрямую не установится.

## Частые ошибки
| Симптом | Что делать |
|---|---|
| Sideloadly не видит iPhone | iTunes/iCloud с apple.com, другой кабель/порт, «Доверять» на телефоне |
| «Режим разработчика» отсутствует | Сначала попробуйте установить приложение; затем пункт появится |
| «Untrusted Developer» | Настройки → Основные → VPN и управление устройством → Доверять |
| Приложение не открывается через неделю | Истёк срок подписи: переустановите поверх |
| Ошибка Apple ID / двухфакторка | Используйте пароль приложения при необходимости, см. подсказки Sideloadly |
| Данные пропали после переустановки | Был сменён Bundle ID/Apple ID или приложение удалено: Профиль → Резервные копии → Восстановить |

## Платная программа Apple Developer Program (99 $/год)
Подпись на 1 год, TestFlight (до 10 000 тестировщиков), публикация в App Store, iCloud/CloudKit-синхронизация, push-уведомления.
Для публикации потребуется: свой Bundle ID, сертификаты и профили (хранить в GitHub Secrets, не в репозитории), иконки/скриншоты, политика конфиденциальности, ревью Apple. Текущий workflow для этого нужно будет расширить шагами archive/export с подписью.
